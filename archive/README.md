# Archive

This directory contains material preserved for history, parity checks, and manual review. Nothing here should be treated as the active production implementation.

- `legacy-crm/`: original HTML/CSS/JavaScript CRM and assets
- `migration-artifacts/`: diagnostic output from the React migration
- `migration-artifacts/verification/`: obsolete verification logic retained for historical context
- `prototypes/`: abandoned or incomplete project structures
- `notes/`: historical notes retained during cleanup

Archived files should only be deleted after a separate review confirms that they are no longer needed.
